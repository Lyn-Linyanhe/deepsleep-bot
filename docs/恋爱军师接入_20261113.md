```
Planner 判定「对方明确求援」→ 调 relationship_counsel(topic)
  → 插件现读 knowledge/*.md，按 topic 关键词打分取 top1-2 + 通用方法
  → 返回摘要正文 + instruction（用小睡口吻、别念框架、别暴露知识库）
  → Replyer 用自己的话组织回复
```

- **知识现读不缓存**：改 knowledge/*.md 即时生效，不用重启。
- **危机强制置顶**：topic 命中「家暴/自杀/跟踪/诈骗」等正则 → 强制返回 21-危机与安全 + 危机 instruction（110/120、不劝和）。

- 不搞独立档案记忆：人物档案/长期记忆仍归 A_Memorix 现有体系，不引入第三套存储。

## 踩的坑（三条都值得记住）

1. **插件最小接口 = 类 + `create_plugin()` + `on_config_update()`**，缺任一个都加载失败（先后报「缺少 create_plugin 工厂函数」「必须实现 on_config_update()」）。
2. **重启过滤器不许用 `*deepsleep*`**：会把 embedding_server(:8100) 和 guardian.py 一起杀掉。正确过滤：`*MaiBot*bot.py*` / `*src.runtime*` / `*runner_main*`。恢复时 embedding 要单独拉起（`cd /d embedding_server && .venv\Scripts\python.exe app.py`），guardian 也没有计划任务兜底，必须手动 `pythonw guardian.py`。
3. **ps1 脚本里别写中文路径**：PowerShell 5.1 无 BOM 按 ANSI 读脚本，`启动MaiBot.bat` 变乱码找不到文件、静默失败。用 ASCII 名 `start_maibot_silent.bat`。
