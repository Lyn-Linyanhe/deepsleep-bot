# 今日费用自然语言查询

部署时间：2026-11-12 15:46，本机时间。

## 功能
- 日报插件新增 Tool `query_today_usage`，只读本机今天00:00到查询时刻的 llm_usage；同时返回最新入账时间。
- 默认口语摘要；detailed=true增加渠道与会话排行；group_name可按群名/群号筛选，歧义时拒绝，不猜群。
- 仅真实QQ100000000可查；授权独立于日报目标收件人配置。其他人或缺失身份拒绝。
- 群内授权查询会把结果发到固定主人私聊；群内工具结果只有成功/失败确认，不含账本数据。
- 统计费用为本地cost列历史值之和，不按当前单价重算；本地估算非供应商实付。
- LLM总量与各分类共用一次只读SQLite事务。生图配额库只有按天累计张数，单独读取并标注，不声称与LLM同一时刻快照；不可读时image_available=false、estimated_total_cost=null，不将未知总费用伪装为零。单群不分摊生图。
- 工具查询不会改sent_days，不影响原定昨日日报。

## 修改
