# 2026-11-17 审计修复更新

本次同步运行部署中两批审计修复。源码以累计补丁分发，未包含生产数据库、聊天、日志、模型权重或凭据恢复文件。

## 改动

- 工具鉴权使用当前真实消息批次的固定身份；混合身份不自动授权。历史主人发言和引用锚点不再提供权限，MaiTrace调用者字段由Host覆盖。
- 睡眠期间消息保存而非直接丢弃；已有会话下一次正常入站时补入静默历史，历史不作为当前授权。清醒休息不按睡眠处理，带锚点发送受睡眠状态约束。
- 首段发送成功立即记录“已开口”；后续发送失败仍保留该事实。单汉字打字延迟遵守速度开关和倍率。
- 模型并发计数支持多个事件循环；热更新不重置存量，取消和异常释放名额。
- 候选检索只计算时效，SDK最终返回的段落才记访问；计数写入失败保留检索结果。摘要语义去重选用就绪的段落向量池。
- 记忆去重改为保守文本等价，避免合并不同主体或否定事实；占位跳过要求明确空增量，且没有实体/关系/事实。
- 私聊摘要自动注入仅限原会话；表达反馈要求结构化通知、匹配会话并持久去重。
- guardian使用Windows命名互斥对象，失败暂停不再无限续期；embedding关闭CPU arena，推理并发最多2个，异常归还名额。
- 空间配图读取Host的emoji对象，静默时段同时约束自动发帖和浏览。
- 公开文档的凭据示例改为占位符；此前使用的相关访问凭据已在运行部署轮换并验证旧值拒绝。

## 验证

部署端20项离线回归通过，其中1项依赖本地发布脱敏工具，不包含在公共测试中；公开版为19项。修改源码编译通过，部署后本地向量推理返回1024维，适配器连接和相关服务恢复。完整上游pytest套件未运行。

## 已知限制

- SDK返回后，启发式注入仍有二次筛选，访问计数不是最终进入提示词的精确次数。
- 无锚点插件直发暂时放行以保留日报/管理回包；口头“晚安”不会自动切换睡眠状态。
- 自动私聊摘要隔离不等于所有记忆工具、画像及图片出口都已完成全链隔离。
- embedding仍需请求总量和重复启动保护；guardian仍是端口级探测，聚合网关自启未完善。
- 旧启停脚本仍需进程树校验，不应盲目执行。凭据轮换不等于清除公开仓历史；本次采用普通提交，没有重写Git历史。
- `config-templates/` 与架构图保留原示例快照；本次不发布生产路由、账号及人设配置，部署时按本地服务重新配置。

历史实现文档保留当时记录；与本更新冲突时，以本次补丁及已知限制为准。
