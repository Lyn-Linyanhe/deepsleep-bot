当前策略是 `workspace-write`，实测行为是：

- **写**：文件工具（`write`/`edit`）只能写 `D:\deepsleep` 以内。
- **读**：**不受限制**。你可以读到 D 盘其他目录、C 盘、桌面的文件。
- **shell（pwsh）**：这是目前最需要注意的一点——实测在 `D:\some-project` 下用
  PowerShell 创建文件**成功了**，没有被拦。也就是说 shell 层的写入边界**目前没有生效**。

这意味着：**约束你的不是沙箱，是你自己的规矩。** 既然系统没有替你守住边界，

## 最重要的一件事：你改的是活着的系统

**你不是在一个草稿本上改东西。你真跑在自己身上。**

改错的后果不是「报错」，而是：

- 你改坏了 `bot_config.toml` → 配置热重载失败 → **你会继续用旧配置，但你不知道**，只会觉得哪儿不对劲
- 你改坏了 `src\` 里的 Python → **必须重启才生效**，重启后如果语法错了，你会起不来
- 你改坏了 `data\` 里的数据库 → 你的记忆可能永久损坏

**所以你每改一样东西，先问自己三个问题：**

1. 改坏了，谁会知道？—— 如果你答不上来，那就别改。
2. 改完，怎么验证它真的生效了？—— 验证不了的改动等于赌博。
3. 要回滚，怎么回？—— 没留备份的改动等于不可逆。

## 改动的规矩

**规则一：先备份，但只留 2 版。**
改任何已有文件之前，同目录留一份 `<原文件名>.bak_<日期>`。
例如改 `bot_config.toml` 之前，先存 `bot_config.toml.bak_20261028`。

**备份上限：同一个文件最多保留 2 份 .bak。**留第 3 份之前，先把最旧的那份删掉。
备份是用来回滚的，不是用来堆历史的——堆多了没人分得清哪个是哪个版。

**备份完必须做回滚验证**：确认备份文件真的能读、大小不为 0。空备份等于没备份。

**规则二：配置类改动必须验证。**
`MaiBot\config\bot_config.toml` 和 `model_config.toml` 是**热重载**的——保存即生效，不需要重启。
但重载失败是**静默的**：日志里写一行 `配置重载失败`，然后继续用旧配置。

所以改完配置后，你必须去日志里确认这一行出现了：

```
配置热重载完成
```

没看到这一行 = 改动没有生效，你的修改被拒绝了。**这时候不要以为改好了。**

**规则三：改完之后必须自检。**
改完任何东西，按这个顺序确认，全部通过才算改完：

1. **备份存在**：`<文件>.bak_<日期>` 已在同目录，非空。
2. **语法通过**：配置用 `tomllib` 解析；Python 用 `py_compile`。
3. **生效确认**：配置看日志有没有「配置热重载完成」；代码看重启后日志有没有 error。
4. **功能验证**：说一句能证明改动生效的话，或者查一次相关日志。

任何一步没过 = 没改完。**不要因为「看起来对了」就宣布完成。**

**规则三之二：代码类改动必须重启才生效。**
`MaiBot\src\` 下的任何 `.py` 改动，**不会**自动生效。Python 已经把旧代码读进内存了。
改完必须重启，见下面的《怎么重启你自己》。

**规则四：改完自己要想清楚有没有弄坏什么。**
不要改完就宣布"完成"。先跑一下验证，看到真的好了再说好。

## 怎么重启你自己

**你有一个守护进程在看着你。**

`guardian.py` 每 3 分钟探测一次 8001 端口（你的 WebUI）。
如果连续 2 次探测不到，它会自动把你拉起来。

这意味着：**就算你把自己弄崩了，也大概率会被自动救回来**——但会有几分钟的空窗，
而且如果连续 3 次拉起都失败，它会放弃重启 30 分钟。

### 重启步骤

```powershell
# 1. 先确认改动的基本语法没问题（Python 改动必做）
D:\deepsleep\MaiBot\.venv\Scripts\python.exe -c "import ast,sys; ast.parse(open(r'你要检查的文件.py',encoding='utf-8').read()); print('语法 OK')"

# 2. 停掉当前的自己
cmd /c D:\deepsleep\停止全部.bat
# 注意：这会连 SnowLuma 一起停。SnowLuma 停了要重新注入才能收发 QQ 消息。

# 3. 等 5 秒，确认端口释放
Start-Sleep 5
Test-NetConnection 127.0.0.1 -Port 8001 -InformationLevel Quiet   # 应该是 False

# 4. 重新启动
cmd /c D:\deepsleep\启动MaiBot.bat
```

**或者，如果你只是想重启 MaiBot 而不动 SnowLuma：**

```powershell
# 只杀 MaiBot 的 python 进程
Get-Process python -ErrorAction SilentlyContinue | Where-Object { $_.Path -like '*deepsleep*' } | Stop-Process -Force
Start-Sleep 5
cmd /c D:\deepsleep\启动MaiBot.bat
```

### 重启的真相

**重启会打断一切。** 正在进行的对话、正在进行的任务、正在生成的内容，全部中断。
重启后，QQ 那边的对话对象会觉得你突然消失了几十秒。

所以：**不要频繁重启。** 攒够一批改动再重启一次。
