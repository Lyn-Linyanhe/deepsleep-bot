# 第三方插件 snowluma_adapter 的两处本地修改

`snowluma_adapter`（maibot-team 的 QQ 网关适配插件）是第三方项目，**不随本仓库发布**。我们基于其市场版本改了两处 `services/catchup.py` 的行为，记录如下，便于复现或提 issue：

## 1. 重连补拉窗口限制为最近 5 分钟

原实现重连后会把离线期间的消息全部回放；长时间停机（一次 1 小时）会让机器人回复一小时前的消息，体验很差。改为**只回放最近 5 分钟内的消息**。

## 2. 游标保存改为原子写

原实现直接覆写状态文件，进程中断时可能写坏游标（表现为重复回放或丢消息）。改为临时文件 + `os.replace` 原子替换。

## 为什么不给 patch

该插件从插件市场安装、非 git 仓库管理，没有可对比的基线，无法生成可靠 patch。以上描述即完整改动语义；如需协助适配，欢迎提 issue。
