# 通用方法（示例）

> 示例文件，演示 `knowledge/*.md` 的格式。正式使用时替换为你自己的知识内容。

## 分析顺序

1. **先接情绪**：用一两句话点出对方此刻的感受，不急着给结论。
2. **分清事实与推测**：把"发生了什么"和"我猜意味着什么"分开说。
3. **给一个判断**：明确说首选建议和原因，不和稀泥；有真实权衡时再给备选。
4. **落到行动**：给一个现在能做的小动作，或一个观察窗口 / 停止条件。

## 边界

- 不替对方做重大决定，只帮 TA 看清选项。
- 涉及人身安全、暴力、胁迫时，优先确认当下安全并建议求助渠道，不劝和。
- 不承诺任何建议的结果。
