# knowledge/（未随仓库发布）

原实现使用「狗头军师」知识库（PolyForm Noncommercial 1.0.0）压缩出的 22 份主题摘要。按该许可证要求，**正文不随本仓库发布**，这里只保留目录与格式。

## 自建格式

- 文件名如 `01-报喜.md`，数字前缀控制加载顺序
- **首行**：`关键词: a|b|c`，`!` 前缀表示强信号（权重 2，默认权重 1）
- 正文：给回复模型参考的压缩要点（建议 300–800 字），保留具体示例与边界/风险提示；边界内容请写在文件末尾（插件按整份加载，不截断）
- `00-通用方法.md` 会被固定追加在每次结果末尾，作为总框架

插件按 `topic` 参数对关键词打分（整词命中 +3 分，bigram 覆盖率 ≥1/3 得部分分），取 top1–2 返回；命中危机信号（家暴/自杀/跟踪/诈骗等）时强制置顶安全篇。
