# cards/（示例卡随附，原卡片未随仓库发布）

原实现的 14 张「说话提示卡」由第三方知识库（PolyForm Noncommercial 1.0.0）衍生，未随仓库发布。这里附两张**自写示例卡**演示格式，可以照着写自己的。

## 格式

```
关键词: a|b|!c
情况: 一句话描述处境
提示: 给回复模型的提醒（≤120 字，第二人称，明确"这是提醒不是台词，别照念"）
```

- 关键词 `!` 前缀 = 强信号（2 分，普通 1 分）
- 匹配阈值：默认 2.0（两个弱信号或一个强信号）；私聊可放宽到 1.0
- 冷却：同卡 15 分钟 / 全局 90 秒 / 每小时 10 次（私聊另有参数，见 `config.toml`）
- 建议每张卡只给**一个动作**，不要堆技巧
